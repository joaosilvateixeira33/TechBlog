# 📰 TechBlog

O **TechBlog** é uma página responsiva de tecnologia desenvolvida com **HTML5 e CSS3**, criada com o objetivo de praticar a construção de interfaces a partir de um layout no Figma e aplicar conceitos de responsividade utilizando a abordagem **Mobile First**.

O projeto apresenta uma seleção de artigos relacionados a programação e tecnologia, além de uma área de apresentação e um formulário de contato.

## 🌐 Projeto no ar

🔗 **Acesse o TechBlog:**
https://joaosilvateixeira33.github.io/TechBlog/

## 📸 Sobre o projeto

O TechBlog foi desenvolvido seguindo um design responsivo, adaptando o conteúdo para diferentes tamanhos de tela.

A página é composta por:

* Hero de apresentação
* Área de artigos recomendados
* Cards de artigos
* Formulário de contato
* Layout responsivo para mobile, tablet e desktop

## 🖥️ Responsividade

O projeto foi desenvolvido utilizando a estratégia **Mobile First**.

### 📱 Mobile

* Hero organizado verticalmente
* Artigos exibidos em uma coluna
* Formulário adaptado à largura da tela

### 📱 Tablet

* Layout com maior aproveitamento de espaço
* Artigos organizados em duas colunas
* Ajustes de espaçamento e dimensões

### 🖥️ Desktop

* Hero organizado horizontalmente
* Texto e ilustração lado a lado
* Artigos organizados em três colunas
* Formulário centralizado

## 📐 Organização dos artigos

A seção de artigos utiliza **CSS Grid** para adaptar automaticamente a disposição dos cards de acordo com o tamanho da tela:

* **Mobile:** 1 coluna
* **Tablet:** 2 colunas
* **Desktop:** 3 colunas

## 🎯 Objetivo

O objetivo deste projeto foi colocar em prática os conhecimentos adquiridos em **HTML e CSS**, desenvolvendo uma interface moderna e responsiva baseada em um protótipo visual.

O projeto também serviu como exercício para entender melhor como transformar layouts criados no **Figma** em páginas web utilizando HTML e CSS.
